# ドルコスト平均法×複利成長シミュレーター

毎月積立×複利成長のシミュレーション。一括投資との比較と景気変動シナリオ付き。

## 機能

- 初期投資額・月次積立額・年間利回り・期間（年）を入力
- 月次複利で最終資産額・総投資額・利益額を計算・表示
- SVGで資産成長曲線グラフ（元本部分と利益部分を色別）
- 一括投資との比較ライン
- シナリオ比較（楽観/中立/悲観の利回り3パターン）
- localStorageで最後の設定を自動保存

## 技術仕様

- バニラJS / Tailwind CDN
- XSSガード: escHtml関数によるユーザー入力のサニタイズ
- レスポンシブ対応
- アクセシビリティ: aria-label付与済み
